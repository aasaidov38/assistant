Вопросы

Коротко о главном

Стоимость, подключение семьи, банки и документация.

Можно ли попробовать без установки?

Да. Откройте демо-кабинет: это настоящая панель с вымышленной семьёй и историей за полгода. Меняйте что угодно, ваши правки видны только вам и через 20 минут без действий сбрасываются. ИИ-чат в демо работает, но с лимитом сообщений.

Можно подключить нашу семью?

Пока ассистент работает для одной семьи. В версии 2.0 появятся два варианта: «коробка» — установка на свой сервер одной командой, и общий сервис по приглашению для знакомых.

Сколько это стоит?

Сервер — обычный недорогой VPS. Погода и бэкап в Яндекс в пределах 1 ГБ бесплатны. Платные только запросы к ИИ: для семьи это небольшие деньги в месяц.

Что будет, если ИИ не понял фразу?

Ассистент переспросит или предложит кнопки выбора. Неверную запись можно поправить кнопкой под ответом или отменить фразой «отмени последнюю трату».

Подтягивает ли он данные из банков?

Официального API для личных карт у банков пока нет. Сейчас работает импорт выписок Сбера (PDF) и Т-Банка (CSV) со сверкой с уже записанным.

Нужно ли что-то скачивать из магазина приложений?

Нет. Панель ставится ярлыком из браузера на компьютер, Android и iPhone. Подробности — на странице «Приложение».

Где посмотреть подробную инструкцию?

В репозитории на GitHub есть инструкция docs/INSTALL.md (41 раздел): от первой установки до каждой команды бота. Для обновлений есть готовые задания для Claude Code.

Остались вопросы?

Откройте панель и спросите ассистента обычными словами — он отвечает по вашим данным.
